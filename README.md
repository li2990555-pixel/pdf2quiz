# pdf2quiz — 对话式AI刷题助手

上传题库文档（PDF/Word），自动解析后以对话形式逐题刷题，支持自然语言指令灵活调取各章节/题型/错题。

## 使用方式

加载 skill 后，在 Claude 对话中上传文件即可。

- AI 逐题出题 → 用户回答 → AI 判题 → 下一题
- 自然语言指令：`先刷第五章的多选题` / `混着刷` / `随机抽20道`
- 自动维护错题本
- 结束后生成 Word 报告

## 自适应解析引擎

不依赖固定模板。对每一行进行行分类打分 + 上下文消歧：

- **章节行**：`第一章` / `导论` / `Chapter 1`
- **题型行**：`一．单项选择题` / `二、多选题`
- **题号行**：`1.` / `①` / `(1)` / `【1】`
- **选项行**：`A.` / `A、` / `对/错`
- **答案行**：`答案：B` / `参考答案：A`
- **自动推断**：2选项→判断、多字母答案→多选、无选项→简答
- **容错**：题号不连续、题干跨行、选项同行紧凑排列
